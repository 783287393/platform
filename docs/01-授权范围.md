# 01 授权范围与白名单门禁

## 1. 书面授权

扫描前必须完成 `scope.md`：资产所有者、目标 URL、允许时间、扫描类型、禁止动作、
联系人与批准人。本实验只扫描本人本地系统、教师环境或专门靶场，不对公网资产测试。

## 2. 门禁规则（core/gate.py）

`check_target(url)` 在平台发起任何请求前执行：

1. 协议必须是 http/https，缺少协议头或其他协议（file:// 等）直接拒绝；
2. 主机名必须命中白名单：`localhost`、`127.0.0.1`、`host.docker.internal`；
3. 地址不允许携带用户名/密码；
4. RFC1918 私网地址（10./172.16-31./192.168.）**不会**自动进入白名单，必须由教师明确登记；
5. 重定向目标由 `check_redirect` 再过同一门禁，初始 URL 授权不代表后续跳转也获授权。

## 3. 边界说明

- 本实验运行被动规则与已知 URL 请求，不含爬虫或主动攻击；
- ZAP 代理/API 只绑定 127.0.0.1，不向公网开放；API Key 由服务端持有，不放进浏览器 JavaScript；
- 真实使用时，白名单与 scope.md 的变更需要批准人确认后再修改 `core/config.py`。
