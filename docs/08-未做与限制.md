# 08 未做与限制（诚实声明）

1. **单机本地、无鉴权**：平台只监听 127.0.0.1，没有登录认证与限流；开放访问前必须补认证。
2. **被动检测边界**：本实验只使用被动规则与已知 URL 请求，不含爬虫遍历与主动攻击；
   不构成完整渗透测试。
3. **样本为脱敏演示数据**：`data/samples/` 两份 JSON 对齐 ZAP 2.17.0 Traditional JSON
   结构，用于演示导入与闭环；真实结论以本机 ZAP 实际导出报告为准。
4. **不宣称应用无漏洞**：修复安全响应头后仍有剩余告警（如 HSTS 提示、Banner 信息），
   剩余风险在平台中如实展示。
5. **未实跑的上游组件**：Docker、DefectDojo、Juice Shop 本环境未部署运行；平台为自建
   Streamlit/SQLite 轻量实现，未对接 DefectDojo API。
6. **覆盖不足不判关闭**：after 扫描未覆盖原页面或规则未加载时，状态保持 Resolved，
   不直接置 Verified。
7. **SQLite 单文件**：适用于课程单机演示，不支持多节点并发写入，不是生产级漏洞管理系统。
8. **自动脱敏不替代人工复核**：导出前仍需人工检查是否残留个人数据或敏感信息。
