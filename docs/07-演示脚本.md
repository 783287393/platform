# 07 演示脚本（5-10 分钟课堂展示）

## 1. 启动

```powershell
cd D:\management-platform
powershell -ExecutionPolicy Bypass -File scripts\start-platform.ps1
```

浏览器打开 <http://127.0.0.1:8501>。

## 2. 演示顺序（对齐实验指导书第 14 条）

1. **概览**：说明法律与范围警告、风险分布与状态分布；
2. **授权范围门禁**：展示 scope.md 与白名单；输入一个公网地址（如 `https://example.com`），
   演示被拒绝并记录；
3. **报告导入**：展示 before 样本导入结果（新建 Finding / 重复归并计数），重复导入一次
   说明不重复创建；
4. **漏洞复核**：打开一条 Confirmed 漏洞，展示负责人、规则、证据与复核理由；
5. **复扫对比**：选择 before/after 批次，展示已关闭 3 条、未变 2 条、新增 0 条；
6. **证据链追踪**：追踪 F-10020：before 实例 → 复核 Confirmed → 修复分支/Commit →
   after 复扫批次 → Verified；
7. **导出与说明**：演示脱敏 CSV/JSON 导出，说明剩余风险与未修复项；
8. **测试证据**：`scripts\run-tests.ps1` 结果与 docs/evidence 原件。

## 4. 真实 ZAP 扫描替换样本（可选扩展）

1. 启动本地目标：`python web\target_app.py --port 8000`（修复前不加 `--headers`）；
2. ZAP 2.17.0 daemon/桌面版对 `http://127.0.0.1:8000/` 发已知 URL 请求，被动检查完成后
   导出 Traditional JSON（before）；
3. 给页面加安全响应头后重启目标，再次导出 after JSON；
4. 在平台「报告导入」页上传两份 JSON，替换内置样本。
